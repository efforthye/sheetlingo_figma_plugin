# Community listing (search-optimized)

## How people find plugins
Figma Community search mainly matches the **name**, **tagline** and **description**, and ranking grows with
installs / likes / recent activity. So: put the words people actually type in the name and first lines,
and get the first installs & likes quickly.

Keywords people search for: **google sheets, sheets, spreadsheet, csv, excel, localization, translation,
translate, i18n, multilingual, language, copy, content, text, sync, data, populate, fill, lorem ipsum**.

## Fields

**Name** (plugin menu stays "Sheetlingo" via manifest; the listing name can carry keywords)

**Tags** (if the tag field is offered): google sheets, localization, translation, i18n, multilingual, csv, spreadsheet, sync text, copy, content, data, populate

**Description (EN)**
```
Sheetlingo keeps every word of your design in a Google Sheet. Link text layers to keys, translate your UI into any language, and re-sync whenever the copy changes — no more copy-paste.

⚡ HOW IT WORKS
1. Paste a Google Sheets link (or a CSV / pasted cells). Sheetlingo checks access instantly.
2. Name a text layer #home.title — or pick a key from the list.
3. Click a language. Done. Sheet changed? Hit Re-sync.

🌍 LOCALIZATION & TRANSLATION
• One column per language: en, ko, ja, zh, es, fr, de… any language code
• Missing translations fall back to your default language automatically
• Report shows missing keys, fallbacks and missing fonts — click to jump to the layer
• PRO: overflow check finds long translations that break your layout

📊 FILL DESIGNS WITH REAL DATA
• Fill text layers from a spreadsheet column in reading order (replace lorem ipsum)
• Fill cards, lists and tables row by row — layer names match column names automatically
• Filled layers remember their cell, so Re-sync keeps them up to date

🔁 KEEP DESIGN AND COPY IN SYNC
• Re-sync from the right panel without opening the plugin
• PRO: auto re-sync while the plugin is open, sync all pages at once
• Search by text: select a layer, see matching keys instantly, click to link
• Auto-link: link every layer whose text already matches the sheet
• Extract text: turn an existing design into key,en rows for your sheet

🎁 FREE & PRO
Free: link up to 100 keys per file (live sync included), 3 languages, 100 text fills and 10 cards per run.
Pro: unlimited keys & languages, all-pages sync, overflow check.
Every new user gets a 7-day Pro trial — no survey, no card.

📌 GOOD TO KNOW
• Private or company sheet? Sign in with Google and pick it — no link sharing needed. Public links work too.
• Row 1 = column names. Each tab has its own link (#gid=…).
• Plugin UI: English, 한국어, 日本語, 简体中文, Español, Français, Deutsch.

🔒 PRIVACY
Sheet data goes straight from Google to your Figma file. Sheetlingo has no server and collects no data.

Keywords: Google Sheets, CSV, spreadsheet, localization, translation, i18n, multilingual, copywriting, content, data populate, text sync.
```

## Assets checklist
- **Icon** 128×128: the green sheet mark (same as the UI logo).
- **Thumbnail** 1920×1080: before/after — same card in EN | KO | JA side by side + big text "Google Sheets → Figma, every language".
- **Carousel** (up to 9): ① connect & access check ② language switch GIF ③ missing-key report ④ card fill ⑤ extract text ⑥ Free vs Pro.
- **Playground file** (strongly recommended — people try before installing): a Figma file with sample screens already linked to a public demo sheet (`docs/sample-sheet.csv`).
- **Support contact**: a personal email or a GitHub Issues / Notion page.

## Launch tips
- First week matters: ask colleagues/friends to install and ❤ like; answer every comment.
- Post a 20-sec GIF on X / LinkedIn / Threads / Figma forum "Show & tell" / Korean design communities, linking the Community page.
- A simple landing page (e.g. sheetlingo.app or a Notion page) with the same keywords helps Google search find the plugin.
- Update regularly — recent updates keep the plugin visible.
